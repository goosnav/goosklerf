HOW TO READ THIS BOOK


Goosklerf II is a modular card-and-dice game. The same deck can be used
to play several different game modes, from quick skirmishes to full
narrative campaigns.

This rulebook is organized in layers:

    CORE RULES are the rules that are always in effect. New players
    should read Parts I and II before their first game.

    ADVANCED RULES are optional modules (Part III). Groups can add
    them selectively as they get comfortable. None of them are
    required for casual play. All are required for competitive play.

    GAME MODES (Part V) describe different ways to play using the same
    cards. Each mode tells the players which rules to use.

    CAMPAIGN SCENARIOS (Part VI) are ready-to-run adventures for
    Campaign Mode.

A player learning the game should read Parts I and II, skim the mode
selector in Part V, and pick Classic Mode for their first game.
Everything else can be ignored until the first game has been played.
